# iCost Analyze

把 iCost 导出的账单拖进网页，按月份查看各货币的优惠金额。

## 开发

```bash
npm install
npm run dev
```

打开 http://localhost:3000，把 `.xlsx` 或 `.csv` 拖到页面上。表格需要包含这些列：日期、类型、金额、一级分类、账户1、账户2、货币、优惠。

## 优惠金额

每种货币分开计算：

- 加上「优惠」列的金额，但排除类型为「支出」且一级分类为「付费卡券」的交易
- 加上类型为「收入」且一级分类为「意外收入」的金额
- 减去类型为「支出」且一级分类为「付费卡券」的花费。这笔金额在表里是负数，扣除时用绝对值

转账优惠已经记在「优惠」列里，不再单独相加。

## 信用卡优惠率

按账户名称分开。只统计「账户1」包含「信用卡」、类型为「支出」的交易。支出金额在表里是负数，作为分母时取绝对值。同一张卡的不同货币分开计算。

- 优惠率 =（这些支出的优惠 + 记在这张卡上的意外收入 + 还款到这张卡的优惠）/ 支出金额
- 还款优惠率 = 还款到这张卡的优惠 / 支出金额

意外收入指类型为「收入」、一级分类为「意外收入」，且「账户1」与该信用卡名称完全一致、货币相同的交易。计入的是它的金额。

还款指类型为「还款」，且「账户2」与该信用卡的「账户1」完全一致、货币相同的交易。

## 页面

- **账单统计**：按月展示优惠。顶栏可以切换账单里出现过的月份，默认是最近的一个月。
- **设置**：查看当前导入的文件，更换文件，或清除页面里的数据。清除不会删除原始文件。
